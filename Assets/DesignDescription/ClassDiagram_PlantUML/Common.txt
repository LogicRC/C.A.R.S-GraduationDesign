' 添加方法注释
note right of CARS.Common::LoadScene
  Scene switching process:
  1. Receive scene name parameter
  2. Directly call Unity's native loading method
  3. Synchronous loading method (will block the main thread)
end note

note right of UnityEngine.SceneManagement.SceneManager
  Unity Scene Management Specification:
  - The scene must be in Build Settings
  - Loading will destroy the current scene object
  - Synchronized loading with no transition effect
end note
